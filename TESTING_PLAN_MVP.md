# План тестирования MVP FOCUS

## Обзор
План тестирования для MVP версии FOCUS - образовательной коммуникационной платформы.

## Архитектура тестирования

### 1. Unit тесты (Jest)
**Цель:** Тестирование отдельных функций и компонентов

#### Ключевые компоненты для тестирования:
- **Хуки (Hooks):**
  - `useAuth` - аутентификация пользователей
  - `useMessages` - управление сообщениями
  - `useNotifications` - система уведомлений
  - `useFavorites` - избранные элементы

- **Утилиты:**
  - `cache` - система кэширования
  - Валидационные функции

#### Тестовые сценарии:
```
src/hooks/__tests__/
├── useAuth.test.ts
├── useMessages.test.ts
├── useNotifications.test.ts
└── useFavorites.test.ts

src/lib/__tests__/
├── cache.test.ts
└── utils.test.ts
```

### 2. Integration тесты (Jest)
**Цель:** Тестирование взаимодействия компонентов

#### Ключевые интеграции:
- Аутентификация + API routes
- Чаты + WebSocket (mock)
- Формы + валидация

### 3. E2E тесты (Playwright)
**Цель:** Тестирование полного пользовательского пути

#### Основные пользовательские сценарии:

##### 🔐 Аутентификация
- **Регистрация нового пользователя**
  - Заполнение формы регистрации
  - Валидация полей
  - Успешная регистрация
  - Перенаправление в dashboard

- **Вход в систему**
  - Ввод корректных учетных данных
  - Валидация входа
  - Перенаправление в dashboard

- **Выход из системы**
  - Клик по кнопке выхода
  - Очистка состояния
  - Перенаправление на страницу входа

##### 💬 Чаты
- **Просмотр списка чатов**
  - Загрузка страницы чатов
  - Отображение списка чатов
  - Поиск по чатам

- **Открытие чата**
  - Клик по чату в списке
  - Загрузка сообщений
  - Отображение интерфейса чата

- **Отправка сообщений**
  - Ввод текста сообщения
  - Отправка сообщения
  - Отображение в списке сообщений

- **Реакции на сообщения**
  - Наведение на сообщение
  - Клик по emoji реакции
  - Отображение реакции

##### 👥 Друзья
- **Просмотр списка пользователей**
  - Загрузка страницы друзей
  - Отображение списка пользователей
  - Поиск пользователей

- **Добавление в друзья**
  - Клик "Добавить друга"
  - Изменение статуса
  - Отображение в списке друзей

- **Создание приватного чата**
  - Клик "Начать чат" у друга
  - Создание нового чата
  - Перенаправление в чат

##### 🔔 Уведомления
- **Получение уведомлений**
  - Имитация получения уведомления
  - Отображение в центре уведомлений
  - Browser notification

- **Управление уведомлениями**
  - Отметка как прочитанное
  - Удаление уведомления

##### 🔍 Поиск
- **Поиск пользователей**
  - Ввод поискового запроса
  - Фильтрация результатов
  - Клик по результату

##### 👤 Профиль
- **Просмотр профиля**
  - Загрузка страницы профиля
  - Отображение данных пользователя

- **Редактирование профиля**
  - Изменение данных
  - Сохранение изменений

## Структура тестов

### E2E тесты (e2e/)
```
e2e/
├── auth.spec.ts          # Тесты аутентификации
├── chats.spec.ts         # Тесты чатов
├── friends.spec.ts       # Тесты друзей
├── notifications.spec.ts # Тесты уведомлений
├── search.spec.ts        # Тесты поиска
├── profile.spec.ts       # Тесты профиля
├── global-setup.ts       # Глобальная настройка
└── global-teardown.ts    # Глобальная очистка
```

### Примеры тестов

#### auth.spec.ts
```typescript
test('Пользователь может зарегистрироваться', async ({ page }) => {
  await page.goto('/auth/register');
  await page.fill('[name="username"]', 'testuser');
  await page.fill('[name="nickname"]', 'Test User');
  await page.fill('[name="phone"]', '+1234567890');
  await page.fill('[name="password"]', 'password123');
  await page.click('button[type="submit"]');
  await expect(page).toHaveURL('/chats');
});
```

#### chats.spec.ts
```typescript
test('Пользователь может отправить сообщение', async ({ page }) => {
  await page.goto('/chats/1');
  await page.fill('[data-testid="message-input"]', 'Привет, мир!');
  await page.click('[data-testid="send-button"]');
  await expect(page.locator('[data-testid="message-list"]')).toContainText('Привет, мир!');
});
```
